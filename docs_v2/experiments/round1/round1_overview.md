# Round 1 Overview

> [!abstract] 문서 목적
> Round 1 실험의 목적과 전체적인 비교 방향을 정리한다.

> [!info] 관련 문서
> [[experiments/baseline|Baseline]] · [[experiments/dataset|Dataset]] · [[experiments/metric|Metric]] · [[experiments/round1/round1_baseline_reproduce|Baseline Reproduction]]

## 1. 목적

Round 1에서는 baseline 방법들이 cross-embodiment offline RL dataset에서 어느 정도의 성능을 보이는지 확인한다.

## 2. 비교 원칙

방법 사이의 parameter 수와 학습 조건은 가능한 범위에서 유사하게 맞춘다. 다만 Round 1에서는 모든 방법의 조건을 엄격하게 동일하게 제한하지 않는다.

## 3. Baseline 재현

각 baseline의 재현 방법과 구체적인 실험 설정은 [[experiments/round1/round1_baseline_reproduce|Baseline Reproduction]] 문서에 기록한다.
